# Local data

Do not commit OC20 or other research datasets to this repository.

Use these directories for local files:

- `raw/` — downloaded or otherwise unmodified source data;
- `samples/` — small local subsets used for exploration and tests; and
- `processed/` — generated outputs from preprocessing experiments.

Record the dataset version, source, and any sampling decisions in project
notes or experiment reports so that local runs remain reproducible.
